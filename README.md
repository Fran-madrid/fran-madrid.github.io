# fran-madrid.github.io

Portada de https://franmorales.dev (lista de apps de Fran Morales) y `app-ads.txt` de AdMob.
Las webs de cada app (`astro-tycoon-web`, `colonia-ares-web`, `nestosaur-web`) salen solas en `franmorales.dev/<repo>/`.

Enlaces de invitación de **¡Lo sabía!**: `losabia/p/` (página para quien no tiene la app) y `.well-known/` (verificación de Universal Links y App Links). Se generan con `npm run web:enlaces` desde el proyecto `Lo sabía`; no editarlos a mano.
